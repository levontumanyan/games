📐 Architecture & Code Reuse Specs

This implementation reuses existing CSS component classes and database structures without requiring breaking schema migrations.

1. Component Reuse

  • .video-trimmer: Base container from styles.css line 2244.
  • .trimmer-track-wrapper & .trimmer-handle: Existing drag track system with enhanced pointer capture and glassmorphic styling.
  • .modal-create-exercise: Upgraded from 880px to 1,120px for spacious 2-column layout.
  • parseTime() & formatTime(): Reused directly from js/utils.js.

2. DB & Data Compatibility

  • Each interval time window maps directly to an entry in the exercise's media_assets array (startSeconds, endSeconds, title).
  • If Full Video is active, startSeconds: 0 and endSeconds: null (entire video).
  • 100% backward compatible with existing routines and workouts.
